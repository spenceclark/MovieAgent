# Run reports

One markdown transcript per recorded sweep in `LlmMoveiAgentResults.xlsx`: every run, every iteration, every tool call, and the grade. Generated by the harness, not by hand:

```bash
dotnet run --project src/MovieAgent -- report runs/<file>.jsonl reports/<name>.md
```

The JSONL under `runs/` is the dataset and is gitignored; these are the readable rendering of it and are committed so they can be linked to. All are graded under `deterministic-substring-v3`, and where a `.regraded.jsonl` existed it was used, so these match the spreadsheet's numbers.

`Strict` is correct **and** having reached every required tool (declines exempt). It differs from `Correct` only where a model landed on the right answer without navigating there.
